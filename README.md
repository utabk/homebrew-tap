# utabk/tap

Homebrew casks for [Marrow](https://github.com/utabk/marrow), a desktop GUI for the REA reverse engineering MCP.

```bash
brew install --cask utabk/tap/marrow
```

Marrow isn't signed yet, so macOS asks before the first launch. To skip that prompt:

```bash
brew install --cask --no-quarantine utabk/tap/marrow
```
